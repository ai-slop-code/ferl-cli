# ferl 0.1.0

First release of the command-line client for self-hosted ferl servers.

- Set up named server/account profiles with `ferl profile`.
- Shorten a URL, optionally with a title and tags; copy the result to your clipboard.
- List and search your links with table or JSON output.
- Delete a link by code or associated short URL.
- Use explicit profile and credential sources for scripts.

## Install

```sh
brew install ai-slop-code/tap/ferl
```

Alternatively, download the archive matching your OS and CPU, verify its SHA-256
checksum, extract it, and put `ferl` on your `PATH`. No Rust installation is needed.
Run `ferl profile` to connect to your server with an existing account's API key.

## Platforms

Archives are provided for macOS and Linux on Apple Silicon/ARM64 and x86_64.
Mac binaries target macOS 13 or later. Linux binaries use static musl and target
kernel 4.18 or later. These minimum OS versions have not been verified directly;
current-platform build/test results are in the release workflow.

Mac binaries have no Developer ID signing or notarization. Linux desktop clipboard
copy uses optional `wl-copy`, `xclip`, or `xsel`; headless use works without them.
